## 目录结构

- `01-数组/` `02-链表/` ...：每个章节一个文件夹，代码与笔记放在一起
- 每章两个文件：
  - `notes.md` —— 本章笔记
  - `*.cpp` —— 本章练习代码

## 笔记模板（每章 notes.md 复制使用）

```markdown

## 是什么
一句话描述 + 适用场景

## 核心操作与复杂度
| 操作 | 时间复杂度 |
|------|-----------|
| - | - |

## 踩坑记录

```

## 每节学习流程

1. 看网课理论（15-30 分钟）
2. 暂停视频，在 Visual Studio 里从空白文件开始敲
3. 敲完和老师对照，报错先自己查
4. 代码文件末尾写"知识卡片"注释（复杂度、易错点）
5. 更新本章 notes.md
6. 提交：commit 信息写清楚完成了什么，push 到 GitHub
