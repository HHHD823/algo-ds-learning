## 目录结构

- `00-数据结构概述/`、`01-线性结构/` ...：知识章节，一个知识点一篇 `.md` 笔记
- `code/`：练习代码（Visual Studio 项目，C 语言），一个知识点一个子文件夹
- `附件/`：笔记里粘贴的图片
- `_模板/`：章节笔记模板，Obsidian 里一键插入
- `学习手册.md`：操作速查（忘了怎么新建文件 / 提交推送就看它）
- `Markdown速查.md`：Markdown 语法速查

## 每节学习流程

1. 看网课理论（15-30 分钟）
2. 暂停视频，在 Visual Studio 里从空白文件开始敲
3. 敲完和老师对照，报错先自己查
4. 代码文件末尾写"知识卡片"注释（复杂度、易错点）
5. 在 Obsidian 里写 / 更新本知识点的笔记
6. 提交：`Ctrl+P` → `Git: Commit and push`，提交信息写清楚完成了什么
