>[!note] 
>顺序表与数组不同

顺序表:（研究元素的逻辑关系）
1. 每个中间元素都要有前驱后继元素。

数组：（研究元素的行为关系）
1. 缺点：运行前就已经确定了它的容量，不能扩容。（原因：数组后的内存可能已经被占用，可能与其他空间连续连在一起）**→固定大小的顺序表**
2. 优点：可在空间内对任意位置进行操作。不要求中间元素都要有前驱后继。只是更灵活的容器，并不表示顺序表前驱后继的逻辑关系。

顺序表（ppt）：
1. 优点：
	1. 逻辑相邻，物理相邻
	2. 无须为表示表中元素之间的顺序关系增加额外的存储空间
	3. 可随机存取任一元素
	4. 存储空间使用紧凑
2. 缺点：
	1. 插入、删除操作需要移动大量的元素（除操作在表尾的位置进行外）
	2. 表容量难以扩充


## 顺序表的逻辑结构

![410](../附件/Pasted%20image%2020260914191158.png)
`element_t *data`：指向正文数据区，一片连续空间。
`capacity`：保证对指针指向的连续空间的访问不越界，数值上为最大元素容量。若`len`=`capacity`，则决定是否扩容。
`len`：数值上为表里的元素个数。指向待插入元素，数值上为下一个待插入位置的尾索引号。保证前驱后继，元素之间没有空格。

以上三个变量封装为表头，表头是一个对象。
表头可放在栈区、堆区、全局区 （灵活）

>后面的数据结构是在基础结构上，不断进行约束。

## 基本运算的实现
### 1. 初始化 时间复杂性：
1. 调用者已经申请了一个表头，需要初始化正文数据区
```c
void initArrayList(ArrayList* table, int num)
{
	table->data = malloc(sizeof(element_t) * num);
	table->capacity = num;
	table->len = 0;
}
```
清除一个表的正文数据区
```c
void deleteArrayList(ArrayList* table)
{
	if (table->data) {		//安全检查
		free(table->data);	//与malloc对应
		table->data = NULL;
	}
	table->capacity = 0;
	table->len = 0;
	
}
```

2. 创建一个表，包括表头区和正文数据区
```c
ArrayList* createArrayList(int num)
{
	ArrayList* table = malloc(sizeof(ArrayList));	//初始化表头区
	if (table == NULL) {
		return NULL;
	}
	initArrayList(table, num);						//初始化正文数据区
	return table;
}
```
释放表头和正文数据区
```c
void releaseArrayList(ArrayList* table)
{
	/*！如果一个接口返回的是一个对象，在释放这个对象时一定不要释放本对象，因为对象里可能还申请了空间*/
	if (table) {
		/*free(table->data);
		table->data=NULL:*/
		deleteArrayList(table);

		free(table);
	}
}
```

### 4.由元素值 返回位置 时间复杂性：O(n)
```c
int findArrayList(const ArrayList* table, element_t val)
{
	for (int i = 0; i < table->len; i++) {
		if (table->data[i] == val) {
			return i;
		}
	}
	return -1;		//找不到，往往返回非法索引号
}
```

### 5. 插入 增
1. 尾插法 时间复杂性：O(1)
- 扩容方法
```c
static int enlarger(ArrayList *table){
	//1.申请一块原空间的两倍大小。
	element_t* temp = malloc(sizeof(element_t) * (table->capacity * 2));
	if (temp == NULL) {
		return -1;
	}
	//2.把原空间的内容拷贝到新空间，原空间[0，len)范围拷贝到新空间的[0，len)范围
	for (int i = 0; i < table->len; i++) {
		temp[i] = table->data[i];
	}
	//3.释放原空间，更新表头
	table->capacity *= 2;
	free(table->data);		//
	table->data = temp;		//这两句话绝对不能调换位置→先free老空间，再 = 新空间
	printf("enlarger success!\n");
	return 0;
}
```

void push_backArrayList(ArrayList* table, element_t val)

2. 在任意位置插入，除末尾  时间复杂性：O(n)
![517](../附件/屏幕截图%202026-09-14%20210101.png)
```c
void insertArrayList(ArrayList* table, int pos, element_t val)
{
	/*要把待插入位置后面的已有的元素，从最后开始往前，把数据向后搬移*/
	//1.判断输入参数有效性
	if (pos<0 || pos>table->len) {
		printf("pos invalid\n");
		return;
	}

	//2.判断是否需要扩容（此操作与pos无关）
	if (table->len >= table->capacity && enlarger(table)) {
		printf("push back fail\n");
		return;
	}

	//3.把原来的[pos,len-1]的元素搬移到[pos+1,len]的位置，i表示要搬移的数据，搬移到i+1的位置
	for (int i = table->len - 1; i >= pos; i--) {
		table->data[i + 1] = table->data[i];
	}

	//4.放入新元素
	table->data[pos] = val;
	table->len++;
}
```

### 6. 删 时间复杂性：O(n) ；尾删时 时间复杂性：O(1)
```c
void deleteValueArrayList(ArrayList* table, element_t val)
{
	/*要把待删除位置后面的已有的元素，从最前面开始往后，把数据向前搬移*/
	//1.找到val的位置
	int pos = findArrayList(table, val);
	if (pos == -1) {
		printf("No element found!\n");
		return;
	}

	//2.将[pos+1,len)区间的数据搬移到[pos,len-1)
	for (int i = pos + 1; i < table->len; i++) {
		table->data[i - 1] = table->data[i];
	}
	table->len--;
}
```
